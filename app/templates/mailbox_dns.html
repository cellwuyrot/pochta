Почта обслуживается Beget

В кабинет
Для этого проекта включена отправка через подключённые почтовые ящики Beget. Записи для самостоятельного почтового сервера сюда не подходят.
  • Оставьте MX доменов почтовых ящиков на Beget.
  • SPF, DKIM и DMARC настраивайте по актуальной инструкции Beget для домена каждого ящика.
  • Домен проекта может отличаться от домена адреса отправителя.
  • Не создавайте вторую SPF-запись и не публикуйте автоматически сгенерированный DKIM проекта вместо ключа Beget.
