# Визуальная и функциональная проверка UI

Выполнена на отдельной временной SQLite БД после согласия пользователя; production-данные не затрагивались. Только фиктивные домены и ключи.

- 24 GET страницы админки/входа, ошибка входа, пустая очередь, раскрытое мобильное меню.
- Полные снимки Chromium: desktop 1440 px, mobile 390 px; каждый соответствующий снимок просмотрен отдельно. Меню проверено в раскрытом мобильном состоянии.
- 54 DOM-проверки ширины/страниц: нет горизонтального overflow документа, неподписанных редактируемых полей, inline styles/handlers или кнопок менее 44 px. Результаты: visual-checks.json.
- Мобильное меню открывается/закрывается, aria-expanded обновляется. Relay/provider passwords отсутствуют в возвращаемом HTML.
- Широкие таблицы и code blocks имеют внутреннюю горизонтальную прокрутку; на мобильном не все столбцы видны одновременно.
- Исправлены нечитаемые нейтральные badges/номера шагов, узкая DNS-кнопка, разрыв SMTP host и адресов в логах, перенос slug, отступы подсказок и синие checkbox.

Это локальная QA рендеринга и DOM, а не проверка всех UI-сценариев через production-браузер, внешнего clipboard, реального DNS или внешней отправки. Backend CRUD/CSRF/permissions/queue покрыты pytest. Несколько примеров снимков находятся в previews/.
